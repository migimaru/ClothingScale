# Changelog

## 0.3.10

- Humanoid情報のない保存済みプロファイルでも、標準ボーン名から左右を識別し、肩などの階層差がある衣装を照合できるようにしました。
- 並び替え一覧の上下端のドロップ判定を広げ、一覧のすぐ外側でも移動できるようにしました。
- HumanoidのUpperArmなどが標準と異なるボーン名の場合に、保存済みの階層から照合できない不具合を修正しました。
- UpperArmの「Left arm／Right arm」「Arm_L／Arm_R」表記にも対応しました。
- 通常のプロファイル選択はUnity標準のプルダウンを維持します。
- 「並び替え」から一覧を展開し、ドラッグ・名前変更・連続削除を行い、完了で一括保存、キャンセルで破棄できるようにしました。
- 並び替え一覧の行をUnity標準の1行入力欄に合わせたコンパクトな高さにしました。
- 並び替え一覧の取っ手をUnity標準のリストと同じ左側に配置しました。
- 通常ボタンを「追加・削除・名前変更・並び替え」に変更し、削除を赤、一覧の編集中を緑で示します。
- プロファイル削除の確認画面を廃止しました。

## 0.3.9

- 衣装全体とボーンのScaleを、プロファイルでまとめて設定できます。
- 左右セット、XYZ連動、複数衣装への一括適用、Undo / Redoに対応します。
